Studio

Type for the next format

Kinetic Type is an independent foundry focused on letterforms that perform under change — scroll, hover, resize, and real-time data. We release retail families and collaborate with product, film, and cultural studios on custom systems.

Every face is drawn for screens first, then proven in print. Every variable axis is stress-tested in motion before it ships.
