The platform

One dependable foundation for every public service.

Civic Stack gives agencies a common set of building blocks so teams stop rebuilding the basics and start serving residents faster.

Accessible from the start

Every component ships tested against WCAG 2.2 AA, with keyboard, screen-reader, and plain-language patterns baked in.

Open and portable

Permissively licensed and standards-based. No lock-in, no per-seat fees — fork it, host it, and shape it to local needs.

Secure by design

Least-privilege identity, auditable records, and privacy defaults that keep resident data in the community's control.

Modules

Compose the services you actually need.

  • Front door

    Service catalog

    A searchable, mobile-first directory that connects residents to the right service in a few taps.

  • Trust

    Verified identity

    Reusable sign-in that meets residents where they are, with no data resold and no dark patterns.

  • Money

    Payments & permits

    Transparent fees, itemized receipts, and refunds that don't require a phone call.

  • Records

    Track a request end to end, with clear status and accountable turnaround times.

  • Reach

    Notifications

    Timely, multilingual updates by the channel each resident prefers.
