The Margin — editor's note

Leave room for the reply

We started Margin because the best writing we knew kept getting shorter, and the world it described kept getting more complicated. So we did the contrary thing: wider columns, longer essays, and a literal margin down every page for the argument you'll want to have back.

Issue 18 asks about the distances we manage — between people, between a decision and its cost, between the thing said and the thing meant. Come read it slowly.

— The editors
