    How a signal is scored

    1. Collect. Nightly pull of the primary record — ledgers, permits, vehicle pings, sign-ins.
    2. Normalize. Each metric is scaled against the city's own five-year range, not another city's.
    3. Weight. Domain metrics are averaged; no single dataset can move a signal more than 20 points.
    4. Publish. Score, inputs, and code notes ship together, so every number can be re-derived.
